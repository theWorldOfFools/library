# .htaccess

**Tujuan**: konfigurasi Apache mod_rewrite untuk seluruh root aplikasi.

**Aturan aktif** (diverifikasi dari source):
1. `RewriteEngine on`
2. `RewriteCond %{REQUEST_FILENAME} !-d` — jangan rewrite jika path adalah direktori.
3. `RewriteCond %{REQUEST_FILENAME}.php -f` — rewrite hanya jika `<path>.php` ada.
4. `RewriteRule ^(.*)$ $1.php` — URL tanpa ekstensi di-rewrite ke file `.php`
   (mis. `/folder` → `folder.php`).
5. `DirectoryIndex folder.php` — `/` melayani `folder.php`.

**Catatan**:
- Ada file kembar `.htacces` (tanpa `s`, typo) dengan isi rewrite yang sama tapi
  **tanpa** `DirectoryIndex` — tidak berpengaruh (Apache membaca `.htaccess` saja),
  tapi sebaiknya dihapus.
- Rewrite hanya jalan jika `mod_rewrite` aktif dan `AllowOverride` mengizinkan.
- Query string (`?poli=...`) otomatis dipertahankan (flag `QSA` default).
