# index — Dependensi

- **db** — koneksi `$conn`.
- **folder** — target redirect (param `poli` kosong).
- **poli** — target redirect (poli = "File Kepegawaian").
- **book-detail** — target link kartu dokumen.
- **search** — target pencarian (JS `kirim()`).
- Aset statis: template Catalog-Z, `img/icon.png` (logo kartu).
