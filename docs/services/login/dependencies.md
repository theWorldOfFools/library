# login — Dependensi

- **db** — koneksi `$conn`.
- **sub-folder** — target redirect setelah login sukses; juga pemanggil (guard home keperawatan/mutu).
- **poli, nama, index3, book-detail2** — pemanggil (redirect saat session expire).
- JS eksternal: animejs (animasi dekoratif form).
