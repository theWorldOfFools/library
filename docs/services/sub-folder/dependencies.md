# sub-folder — Dependensi

- **db** — koneksi `$conn`.
- **login** — target redirect saat `$_SESSION['username']` tidak ada (home keperawatan/mutu).
- **index** — target link kartu poli (yang untuk "File Kepegawaian" mengarah ke `poli.php`).
- Aset statis: template Catalog-Z (css/fontawesome/img).
